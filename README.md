# GD Helper (Chrome Extension)

Многофункциональное расширение для Google Chrome с интеграцией в правую боковую панель (**Side Panel API**) для работы с платформой **GreenData**: упаковка обновлений `.guf`, генератор идентификаторов алгоритмов, инструмент ведения реализации, CSS-стилизация и ИИ-ассистент.

---

## 🚀 Как установить расширение в браузере Chrome

1. **Соберите проект** (если ещё не собран):
   ```bash
   npm install
   npm run build
   ```
   В результате сборки будет создана готовая папка `dist/`.

2. **Откройте страницу управления расширениями в браузере**:
   - Перейдите по адресу `chrome://extensions/` в адресной строке Chrome.
   - Или нажмите меню Chrome (три точки) -> **Расширения** -> **Управление расширениями**.

3. **Включите «Режим разработчика»**:
   - В правом верхнем углу страницы переключите тумблер **«Режим разработчика»** (Developer mode).

4. **Загрузите расширение**:
   - Нажмите появившуюся слева кнопку **«Загрузить распакованное расширение»** (Load unpacked).
   - В открывшемся окне проводника выберите папку `dist` из этого проекта:  
     `d:\Code\Vibe\guf-packer-extension\dist`
   - Нажмите **«Выбор папки»**.

5. **Использование**:
   - В панели инструментов браузера нажмите на иконку расширения **GDHelper** или закрепите его булавкой.
   - При клике справа откроется боковая панель (**Side Panel**) со всеми инструментами GUF Packer!
   - Если нужно развернуть на весь экран или открыть во вкладке, нажмите иконку ⛶ («Развернуть») в шапке расширения.

## 🛠 Возможности

- **Интеграция с Chrome Side Panel**: расширение всегда под рукой сбоку экрана при работе с порталом GreenData.
- **Глобальный Drag-and-Drop**: перетаскивание ZIP-архива или отдельных `.guf` файлов прямо в окно.
- **Умный разбор имён GreenData**:
  - Автоматическое извлечение даты (`YYYY-MM-DD`);
  - Автоматическое извлечение времени (`HH-MM-SS`);
  - Удаление служебных префиксов `ДО.` / `ПОСЛЕ.`;
  - Очистка разделителей и пробелов.
- **Гибкий шаблонизатор**:
  - Теги: `{index}`, `{indexPad6}`, `{cleanName}`, `{date}`, `{time}`, `{originalName}`, `{extension}`;
  - Пользовательские переменные (`{module}`, `{prefix}`, `{author}`);
  - Пресеты шаблонов с сохранением в браузере.
- **Drag & Drop сортировка строк**: перетаскивание элементов таблицы с помощью `@dnd-kit` с моментальным пересчетом порядковых номеров.
- **Валидация перед экспортом**:
  - Поиск недопустимых символов Windows/Linux (`\ / : * ? " < > |`);
  - Предупреждение о дубликатах имён (без учёта регистра);
  - Проверка сохранения расширения.
- **Генератор README.txt**:
  - Индивидуальные описания файлов формируют структурированный реестр;
  - Поле для ввода общих примечаний к обновлению.
- **Экспорт в ZIP**: быстрая компрессия `DEFLATE` в браузере и мгновенное скачивание архива.
- **Автосохранение в IndexedDB**: файлы и настройки сохраняются локально при перезапуске браузера.
