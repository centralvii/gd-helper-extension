## Принципы работы

### Дизайн — бело-зелёный, ВСЕГДА

- Фон страницы: `#f0f4f0`
- Все карточки: белые (`bg-white`) с `border border-gray-200 rounded-xl shadow-sm`
- Акцентный цвет: зелёный GreenData (`#22c55e` / `emerald-500`)
- **НИКОГДА** не используй тёмные фоны (`bg-slate-*`, `bg-gray-800+`, `bg-zinc-*`)
- **НИКОГДА** не используй `rounded-2xl` или `rounded-3xl` для карточек

### Переиспользование компонентов — СТРОГО

- Кнопка с текстом → `<Button>` из `ui/Button.tsx`
- Кнопка-иконка → CSS-класс `.icon-btn` (+ `.icon-btn--danger` для опасных)
- Бейдж/метка → `<Badge>` из `ui/Badge.tsx`
- Текстовое поле → `<Input>` из `ui/Input.tsx`
- Модальное окно → `<Modal>` из `ui/Modal.tsx`
- **Не** дублируй стили и не создавай альтернативные реализации

### Единообразие — ОБЯЗАТЕЛЬНО

- Отступы между карточками-островками: `space-y-3` (12px) — одинаково на всех вкладках
- Паддинги карточек: `p-3`; тулбаров: `p-1.5`
- Строки элементов (файлы, пункты изменений): одинаковый паттерн стилей
- Выпадающие списки: копировать архитектуру `TaskSelector` / `PackageSelector`

### Анимации — VK-стиль

- Все кнопки-иконки через `.icon-btn` получают hover-анимацию (`scale(1.18)`)
- Для особых случаев используй `.vk-icon-pop`, `.vk-icon-shake`, `.vk-icon-spin`, `.vk-icon-bounce`
- Не забывай `transition-all` или `transition-colors` на интерактивных элементах

## Процесс разработки

### Создание нового компонента

1. Определи, к какой папке в `src/components/` он относится
2. Создай файл `ComponentName.tsx` — один экспортируемый компонент на файл
3. Определи интерфейс пропсов в начале файла
4. Используй `React.FC<Props>` для определения компонента
5. Импортируй существующие UI-примитивы вместо дублирования
6. Если нужны новые типы — добавь в `src/types/index.ts`

### Создание нового хука

1. Создай файл `useHookName.ts` в `src/hooks/`
2. Верни объект/кортеж с чётко типизированными значениями
3. Храни побочные эффекты в хуке, не в компонентах

### Стилизация

1. Предпочитай Tailwind-классы инлайн-стилям
2. Для сложных/повторяющихся стилей — используй CSS-классы из `index.css` (`.icon-btn`, `.gd-card`, `.header-tab`)
3. Для слияния классов — `clsx()` + `twMerge()`
4. Цвета — из палитры GreenData (`tailwind.config.js`)

### Модальные окна

1. Всегда используй `<Modal>` из `ui/`
2. Footer — кнопки `<Button variant="secondary">Отмена</Button>` + `<Button variant="primary">Действие</Button>`
3. Закрытие по Escape работает автоматически

## Контекст проекта

**GDHelper Extension** — Chrome-расширение для инженеров GreenData. Работает как боковая панель (Side Panel) с двумя вкладками:

1. **Упаковка** (`packer`) — загрузка .guf-файлов, шаблонизация имён, группировка по пакетам, экспорт в ZIP с README
2. **Реализация** (`implementation`) — составление задач реализации, описание изменений, экспорт в структурированный формат

Пользователи — технические специалисты. Интерфейс должен быть компактным, информативным и отзывчивым.
